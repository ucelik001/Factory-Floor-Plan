# Factory Floor Plan
Visualization of production workflows on a floor layout using intelligent path planning
-	Event-log flows are drawn directly on a user-supplied factory floor plan (SVG)
-	Door- and wall-aware A* routing on a bend-penalised Hanan graph
-	Frequency and waiting-time views at work-center and workstation levels
-	Flow × walking-distance mismatch ranks relocation candidates from real geometry
-	Case study: 154,187 operation events of a discrete manufacturing plant, 2018–2023
